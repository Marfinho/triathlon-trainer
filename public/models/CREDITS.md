# Körpermodell

`body.bin` basiert auf **Blender „Human Base Meshes“ v1.4.1** (Objekt
`realistic_body_male`) von Blender Studio und der Blender-Community.
Lizenz: **CC0 / Public Domain** („All provided assets are public domain under
the CC0 license.“ – README des Pakets). Quelle:
https://www.blender.org/download/demo-files/

Erzeugt mit `scripts/body-model/export_blender.py` (Export der Geometrie) und
`scripts/body-model/build.ts` (Skalierung auf 175 cm, Skinning an das
LocalHub-Skelett, Kleidungsbereiche, Muskelzonen).
